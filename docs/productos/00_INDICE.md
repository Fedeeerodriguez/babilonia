## Regla anti-confusión (resumen)
- **PLUS y EDUCACIÓN** = ahorro con **primas programadas**. Plus = para uno mismo/retiro
  (puede ser PPR deducible). Educación = para un hijo (Fideicomiso Educacional +
  continuidad de aportaciones si el titular falta).
- **PATRIMONIAL y ELITE** = **inversión de un capital**. Patrimonial = fideicomiso en
  pesos + blindaje. Elite = multi-moneda (dólares/euros/renta variable), ticket más alto.
- **PROTECCIÓN** = seguro de vida puro, NO ahorra.
